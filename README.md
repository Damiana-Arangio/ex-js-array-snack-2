<h1 align="center">JS Snacks – Array Avanzati</h1>

Raccolta di esercizi JavaScript focalizzati sull’utilizzo dei **metodi avanzati sugli array**, sulla manipolazione di **oggetti complessi** e sulla gestione di **operazioni asincrone** tramite Promise.

## Obiettivo

- Consolidare l’utilizzo dei principali metodi sugli array (`map`, `filter`, `reduce`, `sort`, `some`, `every`)
- Lavorare con array di oggetti annidati
- Applicare trasformazioni e aggregazioni di dati
- Gestire operazioni asincrone con **Promise.all**

## Descrizione esercizi

Gli esercizi sono basati su un array di oggetti che rappresentano libri, ciascuno con informazioni come titolo, numero di pagine, autore, disponibilità, prezzo e tag.

La **consegna completa di tutti gli snack** è riportata nel file `index.html`.

Ogni snack è risolto in un **file JavaScript dedicato**, collegabile singolarmente per evitare output multipli e confusione in console.

## Struttura del progetto

- `index.html`  
  Contiene il testo completo degli esercizi e il collegamento ai file JavaScript.

- `script-snack1.js`  
- `script-snack2.js`  
- `script-snack3.js`  
- `script-snack4.js`  
- `script-snack5-bonus.js`  
- `script-snack6-bonus.js`  
- `script-snack7-bonus.js`  

I collegamenti ai file JavaScript sono **commentati** e possono essere attivati singolarmente per testare ogni soluzione senza sovrapporre gli output in console.

## Tecnologie utilizzate

- JavaScript (ES6+)
- Promise / Promise.all
- API REST (server locale)
- Postman (per il test delle API)
